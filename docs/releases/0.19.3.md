# Voice PE Realtime 0.19.3 — discussions by voice, whole spoken prompts

Add-on version `0.19.3`, 2026-10-16. Builds on [0.19.2](0.19.2.md). Full entry in
the [changelog](../../openai_realtime_voice_agent/CHANGELOG.md).

## What changes

- **Discussions by voice (off by default).** With `discussions_enabled` and an
  agent bridge that supports the `discuss` contract, the owner can ask what
  needs them and talk an open item through. Only topic and question are said
  unless details are asked for; a decision is read back, staged after a clear
  yes, and confirmed by the owner by text. See DOCS.md and
  docs/configuration.md.
- **Spoken prompts keep their first word.** Cached prompt clips no longer begin
  mid-word; all cached Live lines render again on first start.
- **A wake as a session closes is kept.** The close no longer sends the device
  to idle right after a new wake.

## Verification

Suite green; Workshop real-audio trials: a full discussion in one session (list,
open, decide, read-back, stage), the fallback clip heard whole, and every
re-rendered prompt transcribed against its text on both devices.
